# Design System

## Philosophy
ORYZO-level premium UI. No AI purple. No dark mode except editorial.
Glassmorphism + Cutting Mat aesthetic.

## Typography
- Syne 800 — Headlines, CTAs
- Instrument Serif Italic — Accents
- Fragment Mono — Labels, coordinates
- Inter — Body text
