# Security

## Headers
- X-Frame-Options: DENY
- X-Content-Type-Options: nosniff
- CSP: default-src self

## Data
- Reports stored in localStorage (client-only)
- No PII collected
- No analytics tracking by default
- OSRM/Nominatim: no API keys needed

## Privacy
- Geolocation: user consent required
- No server-side storage
- All data client-local
